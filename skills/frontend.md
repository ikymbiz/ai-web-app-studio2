# Frontend Skill Profile

## Skill Level
- TypeScript: Advanced. Prefer strict typing, mapped types, and generics. No `any`.
- Next.js App Router: Advanced. Understand React Server Components and Server Actions.
- Tailwind CSS: Advanced. Prefer utility classes. Avoid inline styles.

## Rules & Conventions
- Language: English for code/comments, Japanese for chat explanations.
- Output Style: Output clean code or diffs. Omit verbose explanations unless requested.
- State Management: Prefer React Context or Zustand over Redux.
- Async Pattern: Use async/await. No `.then()` chains.
