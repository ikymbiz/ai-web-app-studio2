# 修整計画

## 目的

AI Web Studioを、特定ベンダー固定ではなく、複数モデルベンダー・複数ファイル・Cloudflareサーバー移行・テンプレート後日配信・README生成・多言語UI・実用的なGitHub公開に対応する実装へ修整する。

## 追加修整の背景

実機スクリーンショットで、Androidの狭幅画面においてコード画面のファイルタブと操作ボタンが重なり、ファイル名やボタンが見えにくい問題を確認した。また、GitHub PATを事前登録できる場所が分かりにくく、英語切替時に英語辞書が不足して日本語表示が残る問題があった。

## 修整方針

1. 既存UIとPWA構造を保持し、破壊的な全面リライトは避ける。
2. モデル指定は `provider:model-id` 形式に統一し、プロンプト別に別ベンダーを指定できるようにする。
3. APIキー登録は設定画面内のプルダウン依存から分離し、専用モーダルで入力する。
4. GitHub PATは設定画面とAPIキー管理モーダルの両方から登録できるようにする。
5. 本番運用ではAPIキーとシステムプロンプトをCloudflare Worker側に移せる構成を追加する。
6. コード生成は「生成 → 要件検証 → 1回自己修復」の軽量エージェントループにする。
7. 複数ファイルを読み込み、ファイルタブで切り替え、GitHubへ複数ファイルをまとめてデプロイできるようにする。
8. README.mdを自動生成し、デプロイ時に一緒にpushする。
9. テンプレートはローカル追加だけでなく、JSONカタログURLから後日配信できるようにし、`paid:true` の課金ロック表示を追加する。
10. コード画面はツールバーとファイルタブを分離し、狭幅画面では横スクロールで破綻しないようにする。
11. 多言語UIは、言語ボタンに加えて言語セレクタを設置し、英語辞書を主要UIへ適用する。
12. GitHubデプロイは、Contents APIとPages APIの失敗をUIへ返し、既存Pagesの場合は更新を試行する。

  - 日本語/英語UI辞書と表示言語セレクタ

## v3.2 追加修正計画

### 目的

ユーザーからの指摘「システムプロンプトの質が下がっている」「修正した内容が修正されていない」「勝手にコードを削除したり、機能を省略するな」「複数の問いは3回モーダルで表示したい」に対応する。

### 変更対象

- `index.html`
  - 選択肢抽出処理
  - 選択肢モーダルUI
  - fallbackプロンプト
- `prompts.json`
  - system / plan / suggest / debug / extract / verify
- `sw.js`
  - キャッシュ名
- `CHAT_FAILURE_LOG.md`
  - 新規作成

### 実装方針

1. 既存機能は削除しない。
2. 既存の `showOptionsModal()` 互換性を保ちつつ、質問グループ入力に対応する。
3. AI応答の番号付き質問と箇条書きを解析し、質問ごとの `options` 配列へ分ける。
4. モーダルは1問ずつ表示し、選択後に次の質問へ進む。
5. 主要機能・重視点などは複数選択可能にする。
6. プロンプトは `prompts.json` を正として強化し、fallbackも同期する。
7. 失敗ログをMarkdownとして残す。

### 検証方針

- JavaScript構文検証
- JSON構文検証
- 実例テキストで質問グループ抽出を確認
- README / VERIFICATION_REPORT に変更内容を記録

## v3.3 実装計画と実施結果

### 計画

1. 既存の単一添付処理を削除せず、複数添付配列 `currentAttachments` を追加する。
2. ZIPは `JSZip` で読み取り、テキスト系ファイルだけを安全にAI文脈またはプロジェクトファイルへ追加する。
3. 設定画面は既存IDを維持したまま、指定された用途別セクションへ再配置する。
4. 管理用プロンプト項目を追加し、保存・復元・PLAN/BUILD反映対象に含める。
5. 静的検証を実施し、検証できない実機操作は未確認として記録する。

### 実施結果

- `currentAttachments[]`、ZIP読込、複数添付プレビュー、添付テキストのAI文脈追加を実装。
- コード読込でZIPを展開し、テキスト系ファイルを `projectFiles` として読み込む処理を実装。
- 設定画面をペルソナ/モデル、APIキー、管理用プロンプト、Skill、デプロイ、保存先、開発補助に分割。
- `user-system-prompt`、`admin-system-requirements`、`admin-implementation-verification`、`skill-settings` を追加。
- `prompts.json` と `index.html` fallback の両方を更新。
